# 公共头部：问卷回访

本文记录公共头部问卷回访的现有行为。前端规则依据当前组件代码，后台管理能力依据 2026-10-13 浏览器页面核对；未核验后端分配算法和状态枚举。

## 后台管理

管理入口：[后台 → 支持中心 → 问卷回访](https://admin.deepberry.cn/cms/support/survey)。

后台列表支持按组织、用户、评级和状态筛选，显示状态、主题、用户所属组织、用户、评星、发送时间和回复时间，并提供查看、更多操作及批量删除入口。

“发布问卷”表单包括：

-   组织：必填。
-   发送对象：界面提供“仅创始人”“全部成员”“指定成员”；未选择组织时选项禁用，默认选中“仅创始人”。具体可用条件未进一步核验。
-   消息：必填，作为用户问卷中的提示内容。
-   主题：表单提供该字段。

本次只查看后台列表和发布表单，未发布、修改或删除问卷。后台列表的状态文案不能直接等同于前端接口 `status` 的数值定义。

## 登录与问卷获取

组件库演示页在初始化时通过 `User.getToken({ version: 2 })` 判断模式。该方法读取 URL 临时 token、sessionStorage 或 localStorage 中的 `TOKEN_TITAN_V2`。

-   有 token：关闭静态预览模式，使用现有鉴权请求加载真实用户数据。
-   无 token：使用静态预览用户和演示组织，不请求问卷。

此判断检查 token 是否存在，不验证有效性；存在但失效的 token 仍走真实接口请求。不同端口的浏览器存储相互隔离，3800 的本地登录态不会自动共享给 3801。修改本地 token 后需刷新演示页重新判断模式。

真实模式下，头部获取用户信息；有用户 ID 时，加载组织及问卷。问卷接口为 `GET user/survey`，取响应的 `data.data`，没有数据时使用空对象。

## 入口和红点

显示条件为：

```js
!!survey.id && !survey.status;
```

即问卷有 ID，且 `status` 为假值时，头像下拉菜单显示“问卷回访”。它位于“联系方式”下方，使用 Element Plus 的 `EditPen` 图标，带红点；顶部工具区不再显示独立问卷按钮。

入口不额外限制创始人或超管身份；是否存在待填写问卷由接口返回决定。红点与入口使用同一条件，表示仍有待填写问卷，而非是否打开过弹窗。打开或关闭不会消除红点。

## 自动提醒与手动打开

待填写条件变为成立时，`Extend.vue` 检查 localStorage 中的 `lastSurveyTipDate`：

-   没有日期记录或记录不是今天：自动打开弹窗。
-   记录是今天：不自动打开，仍可通过菜单手动打开。

“今天”使用浏览器本地 `new Date().toDateString()` 判断。关闭弹窗时记录当天日期，提交成功关闭时也会记录。日期不是在弹窗打开时记录，因此打开后未关闭便刷新，仍可能再次自动弹出。

提醒记录没有按账号、组织或问卷 ID 区分，同一浏览器、同一站点下共用。当前没有定时轮询或跨天定时器；自动提醒检查由待填写条件监听触发，不保证页面持续打开时午夜自动弹出。

点击菜单入口通过 `User2.vue → Index.vue → Tools.vue → Extend.vue` 打开原有 `Survey.vue` 弹窗，不经过新的问卷页面。

## 填写和提交

问卷展示接口返回的 `survey.message`，要求填写：

-   评分 `rate`：1 ～ 5 分，必填。
-   问题反馈 `content`：必填，输入框限制最多 200 字。

缺少评分、反馈或正在提交时，提交按钮禁用；提交前再执行表单校验。提交方法有 500ms 节流和 `loading` 防重复提交。

提交接口为 `POST user/survey/{id}`，请求体包含 `rate`、`content`。

提交成功后：

1. 显示成功通知。
2. 触发更新事件，头部重新请求 `GET user/survey`。
3. 关闭问卷弹窗并记录当天提醒日期。
4. 根据重新获取的 `id/status` 决定是否保留入口和红点。

提交失败不会执行成功通知、刷新问卷或关闭弹窗，`finally` 会恢复提交状态，用户可保留当前输入重试。`Survey.vue` 本身没有单独的失败提示处理，具体错误提示取决于请求层。

## 关闭和未提交内容

关闭弹窗不提交答案，也不改变问卷状态，但记录当天提醒日期。

弹窗使用 `v-if="surveyVisible"` 挂载。关闭后组件销毁，再次打开会重新创建空表单，未提交的评分和反馈不会保留。

## 实现位置

-   `src/App.vue`：演示页根据 token 选择真实或静态模式。
-   `src/components/Common/Header/Index.vue`：加载用户、组织和问卷，接收更新事件。
-   `src/components/Common/Header/User2.vue`：问卷菜单入口、红点、点击事件。
-   `src/components/Common/Header/Tools.vue`：转发弹窗打开及刷新事件。
-   `src/components/Common/Header/Extend.vue`：自动提醒、日期记录和弹窗显示状态。
-   `src/components/Common/Header/Survey.vue`：问卷展示、填写、校验和提交。
-   `src/service/account.js`：问卷获取及提交接口。
